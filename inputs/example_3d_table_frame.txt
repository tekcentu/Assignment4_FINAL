# Example 3D building cell: 4 columns + 4 ring beams ("table" frame).
#
# Geometry (Y is the vertical axis in this program):
#   bases  1-4 at y=0:  (0,0,0) (4,0,0) (4,0,4) (0,0,4)   — fully fixed
#   tops   5-8 at y=3:  one column above each base
#   beams  ring 5-6-7-8-5 at the top
#
# Loads:
#   * gravity UDL 12 kN/m on every beam (MEMBER_UDL ... gravity)
#   * wind +X on the x=0 face top corners (nodes 5 and 8) via LOADS3D
#
# Everything is drawn as plain FRAME members; the solver promotes them
# to 12-DOF space elements automatically because the nodes carry z.
#
# GUI walkthrough to build this interactively:
#   1. View -> Work plane -> XY, draw the z=0 portal (columns 1-5, 2-6,
#      beam 5-6) with the Frame tool.
#   2. View -> Working depth... = 4, draw the z=4 portal the same way.
#   3. View -> Work plane -> XZ (plan) to SEE both portals; select a
#      top-node pair (Shift-click) and Model -> Connect selected
#      nodes... for each of the two cross beams.
#   4. Support tool on each base with ux/uy/rz + uz/rx/ry checked.
#   5. Run -> Solve; inspect in View -> Work plane views or the
#      3D viewer.

# ═══════════════════════════════════════════════════════════════════
#  Example 11 — Combined showcase ("kitchen sink")
#  Combines EVERY major modelling feature in one model:
#    • named LOAD CASES (DEAD / LIVE / WIND)
#    • LOAD COMBINATIONS (ULS / ULS_W / SLS)
#    • per-frame RIGID END OFFSETS on the moment frame
#    • diagonal TRUSS bracing
#    • MODAL analysis (element self mass + lumped floor masses)
# ═══════════════════════════════════════════════════════════════════
#
#   5(0,8) ───beam6 (offsets)─── 6(6,8)
#     │  ╲                        │
#  col2   ╲ brace8             col4
#  (off)    ╲                  (off)
#     │       ╲                  │
#   3(0,4) ───beam5 (offsets)─── 4(6,4)
#     │  ╲                        │
#  col1   ╲ brace7             col3
#  (off)    ╲                  (off)
#     │       ╲                  │
#   1(0,0)                      2(6,0)     ← both bases fixed
#
#  Concrete moment frame (FRAME, with 0.25 m rigid joint zones) braced
#  by steel diagonals (TRUSS — no offsets, as the parser requires).
#  Both materials carry density so the modal solver runs.
# ═══════════════════════════════════════════════════════════════════

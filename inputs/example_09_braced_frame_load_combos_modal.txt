#  Example 09 — Two-story braced frame
#  Combines: named LOAD CASES + LOAD COMBINATIONS + diagonal TRUSS
#  bracing + MODAL analysis (self mass + joint masses).
# ═══════════════════════════════════════════════════════════════════
#
#   5(0,8) ───beam6─── 6(6,8)
#     │  ╲              │
#  col2  ╲brace8     col4
#     │     ╲          │
#   3(0,4) ───beam5─── 4(6,4)
#     │              ╲ │
#  col1            brace7
#     │              ╲ │
#   1(0,0)            2(6,0)        ← both bases fixed
#
#  Frame columns/beams are concrete FRAME elements; the two diagonals
#  are steel TRUSS braces (one per story). Gravity UDLs live in the
#  DEAD and LIVE cases; lateral wind is the WIND case. Three design
#  combinations are predefined. Both materials carry density, so the
#  modal solver runs (joint masses lumped at the floor levels).
# ═══════════════════════════════════════════════════════════════════

# Final Verification: Cantilever Beam with Tip Load

This verification case uses `examples/final_demo/verification_cantilever_or_simple_beam.txt` and is intentionally simple enough to check by hand.

## Model and units

- Units: kN and m.
- Geometry: one horizontal cantilever frame element, fixed at node 1 and free at node 2.
- Length: `L = 4.0 m`.
- Tip load: `P = 10.0 kN` downward at the free node.
- Elastic modulus: `E = 210000000 kN/m²`.
- Moment of inertia: `I = 8.0e-6 m⁴`.
- Flexural rigidity: `EI = 1680 kN·m²`.

## Hand calculations

For a prismatic cantilever beam with a downward free-end point load:

- Tip vertical deflection magnitude: `δ = P L³ / (3 E I) = 10 × 4³ / (3 × 210000000 × 8.0e-6) = 0.126984126984 m`.
- Tip rotation magnitude: `θ = P L² / (2 E I) = 10 × 4² / (2 × 210000000 × 8.0e-6) = 0.047619047619 rad`.
- Fixed vertical reaction: `+10.0 kN`.
- Fixed end moment magnitude: `P L = 40.0 kN·m`.
